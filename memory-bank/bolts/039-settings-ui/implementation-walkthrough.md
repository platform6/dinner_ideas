### Decisions

- **`fetch` over `supabase.functions.invoke`** — precise status + error-body mapping to
  `ClaudeErrorCode`. Session token pulled from `supabase.auth.getSession()`.
- **react-query in the component** (not a separate `hooks.ts`) — `ClaudeAiCard` is the only
  consumer; `useQuery(['ai-config'])` + four `useMutation`s that `invalidateQueries` on
  success.
- **UI gate is not the security gate** — non-owner controls are simply not rendered; the
  server (RLS owner policies on `household_ai_config` + the `security definer` owner checks in
  the RPCs, bolt 037) is the real enforcement.
- **Key hygiene** — the key input is `type=password`, `autoComplete="off"`, cleared on submit
  and on unmount, and never read back from the server (`fetchAiConfig` returns only `keySet`).
